X Follow Overlay

Dots on x.com profile pictures. Free with the account you’re already signed into.

  1. 1 Sign in on x.com

    Open x.com in this browser and sign in. Sync uses only that tab.

  2. 2 Run the first Sync

    Leave the x.com tab open. Large accounts take longer because x.com limits how fast a tab can read follows.

    Want faster syncs? Add your own X API keys (paid, optional). The free sync keeps working. settings README

    Stays on this Mac, only sent to X.
